# 拾股 Stockfolio

繁體中文的台股／美股個人觀察名單與研究筆記網站。網站及資料可放在自己的 Cloudflare 帳號，日常使用不需要 Omni、Codex、公司帳號或 VPN。

目前公開介面：[GitHub Pages](https://larchang-create.github.io/stockfolio/)。這個網址仍是本機儲存預覽；個人雲端網址為 https://stockfolio.larry17342.workers.dev/ 。目前改用網站密碼登入，仍待設定 Secret、確認正式部署與跨裝置驗證。

## 使用方式

- 左側：台股、美股、總經概況、研究院。
- 加入觀察名單：市場 → 代號 → 加入。
- 編輯數值、筆記、檢視紀錄及下次日期；支援 JSON 備份還原與 CSV 匯入。
- 研究院以六個問題整理商業模式、成長、品質、投入、估值及失效條件；個人草稿與 AI 報告分開。
- 雲端版使用個人網站密碼登入，同步名單、資料欄位、研究草稿與已有報告。每 30 秒及頁面重新聚焦時檢查更新；修改會主動送出。
- 已開啟頁面在斷線時，修改保留在帳號專屬的本機暫存，恢復連線後重試。清除瀏覽器資料會刪除尚未同步的修改；網站不是離線安裝 App。
- 不同欄位會合併；同欄位有衝突時由使用者選擇此裝置或雲端版本。刪除與遠端修改有衝突也會詢問。
- 未部署時清楚顯示「本機儲存」，不宣稱已同步。

## 部署

先完成網站密碼與資料同步，再啟用資料抓取及分析。步驟見 [SETUP.md](SETUP.md)。

雲端架構：同一個 Cloudflare Worker 提供網站及 API，D1 儲存單人資料與工作階段；只需在 Worker Secret 設定 SITE_PASSWORD。後端驗證已簽章且可撤銷的 Cookie、有效時間，限制登入嘗試次數。未登入時顯示登入頁，設定未完成時提供設定提示。資料庫由部署自動準備，不用 Zero Trust／Access，不用為登入綁付款方式。

Cloudflare 所有權屬於個人；原 GitHub Pages 可繼續當介面預覽及備份匯出入口。兩個網址的瀏覽器儲存各自獨立，請先在舊網址匯出備份，再至雲端版匯入。

## 開發與驗證

Node.js 22.13 以上（測試使用內建 SQLite）：

```sh
npm test
python3 tests/run_browser.py
```

靜態預覽：`python3 -m http.server 8080 --directory public`。沒有雲端登入的本機預覽使用 localStorage。

測試涵蓋真正 SQLite 的同步交易與失敗回滾、過期版本拒絕、離線重啟、兩裝置合併、刪除、筆記衝突、密碼登入與授權、網頁既有操作。這些是本機驗證，不代表已在個人 Cloudflare 上完成兩台實機驗收。

## 資料與下一階段

JSON 備份：`{schemaVersion:1,exportedAt,stocks:[]}`。匯入 JSON 會確認後取代目前名單；CSV 新增紀錄，拒絕重複代號。ID 會保留，避免跨裝置重新產生識別。

最多 1000 檔／帳號，單檔 JSON 750 KB，整次同步 6 MB；超過會回報錯誤並保留本機待同步資料。

資料抓取及 AI 分析的程式保留於 `backend/research.mjs`，此階段不自動啟用，也不會在新增股票時呼叫付費模型。尚無已驗證的真實報告、即時行情、背景排程或通知。範例為虛構資料。
